# お天気チェッカー

都市名を入力すると、その都市の**現在の気温**と**今後48時間の気温の推移(グラフ)**を表示するWebアプリです。

- 天気データ: [Open-Meteo Forecast API](https://open-meteo.com/en/docs)(APIキー不要)
- 都市名 → 緯度経度の変換: [Open-Meteo Geocoding API](https://open-meteo.com/en/docs/geocoding-api)
- グラフ: [Chart.js](https://www.chartjs.org/)
- HTML・CSS・JavaScriptのみで構成(ビルド不要)

## 使い方

1. このリポジトリをダウンロード(または `git clone`)します。
2. `index.html` をブラウザ(Chrome、Edge、Safari、Firefox など)で開きます。
3. 最初は「京都」の天気が表示されます。
4. 入力欄に都市名を入力して「検索」ボタン(または Enter キー)を押すと、その都市の天気が表示されます。
   - 日本語(例:`東京`、`札幌`、`那覇`)でも英語(例:`Paris`、`New York`)でも検索できます。
   - 同じ名前の都市が複数ある場合は、最も代表的な1件が表示されます。地域名・国名は都市名の下に表示されるので確認してください。

## 画面の見かた

- **現在の気温カード**: 都市名、地域・国名、天気(アイコンと日本語)、現在の気温、データの時刻(現地時刻)を表示します。
- **気温の推移グラフ**: 今後48時間の1時間ごとの気温を折れ線グラフで表示します。グラフにカーソルを合わせる(スマホではタップする)と、その時刻の気温が表示されます。グラフの下には48時間の最高・最低気温を表示します。

スマートフォンの画面幅でも見やすいレイアウトになっています。

## 注意事項

- インターネット接続が必要です(Open-Meteo API と Chart.js の CDN にアクセスします)。
- Open-Meteo は非商用利用であれば無料・APIキー不要で使えます。詳しくは [Open-Meteo の利用条件](https://open-meteo.com/en/terms) を確認してください。
