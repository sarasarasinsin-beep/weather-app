# お天気チェッカー

都市名を入力すると、その都市の**現在の気温・降水確率・降水量**と**今後48時間の気温・降水確率・降水量の推移(グラフ)**を表示するWebアプリです。

- 天気データ: [Open-Meteo Forecast API](https://open-meteo.com/en/docs)(APIキー不要)
- 都市名 → 緯度経度の変換: [Open-Meteo Geocoding API](https://open-meteo.com/en/docs/geocoding-api)
- グラフ: [Chart.js](https://www.chartjs.org/)
- 地図: [Leaflet](https://leafletjs.com/) + [地理院タイル](https://maps.gsi.go.jp/development/ichiran.html)(国土地理院、APIキー不要)
- 街の情報: [ウィキペディア日本語版](https://ja.wikipedia.org/) の API(APIキー不要)
- HTML・CSS・JavaScriptのみで構成(ビルド不要)

## 使い方

1. このリポジトリをダウンロード(または `git clone`)します。
2. `index.html` をブラウザ(Chrome、Edge、Safari、Firefox など)で開きます。
3. 最初は「京都」の天気が表示されます。
4. 入力欄に都市名を入力して「検索」ボタン(または Enter キー)を押すと、その都市の天気が表示されます。
   - 英語・ローマ字(例:`Kyoto`、`Paris`、`New York`)で検索できます。
   - 日本の主な都市(都道府県庁所在地・政令指定都市など)と一部の海外主要都市は、日本語(例:`東京`、`札幌市`、`パリ`)でも検索できます。
   - Open-Meteo の検索は日本語の地名にほとんど対応していないため、アプリ内の対応表(`app.js` の `CITY_ALIASES`)で英語名に変換しています。日本語で見つからない都市は、ローマ字で入力してください。
   - 同じ名前の地名が複数見つかった場合は、都道府県名・国名つきの候補一覧が表示されます。候補を押すと、その地域の天気が表示されます(別の候補を押せば切り替えられます)。
   - 初期表示の「京都」だけは、候補を選ばずに京都市の天気をそのまま表示します。

## 画面の見かた

- **現在の気温カード**: 都市名、地域・国名、天気(アイコンと日本語)、現在の気温、現在の時間帯の降水確率と降水量(1時間あたり)、データの時刻(現地時刻)を表示します。
- **気温・降水量・降水確率のグラフ**: 今後48時間の1時間ごとの値を1枚のグラフで表示します。
  - 気温:オレンジの折れ線(左の目盛り)
  - 降水量:青い棒グラフ(右の目盛り、mm)。目盛りは最低でも0〜5mmにしているので、少しの雨が大雨のように見えることはありません。
  - 降水確率:グラフのすぐ下の色の帯。確率が高い時間ほど濃い青で、6時間ごとの最大値を%で表示します。
  - グラフや帯にカーソルを合わせる(スマホではタップする)と、その時刻の気温・降水量・降水確率が表示されます。
  - グラフの下には48時間の最高・最低気温、最大降水確率、合計降水量(雨の予報がなければ「雨の予報はありません」)を表示します。
- **直近の詳しい予報**: 右上のメニューで「1時間」「2時間」「3時間」「4時間」から選ぶと、今からその時間までを拡大して表示します(最初は3時間)。
  - Open-Meteo の15分ごとの予報を使い、気温の折れ線と15分ごとの降水量の棒グラフを表示します。
  - 降水確率は15分ごとの予報がないため、その時間帯(1時間ごと)の値を下の帯に表示します。
  - 日本など一部の地域では、15分ごとの予報は1時間ごとの予報をもとに補間した値です。
- **周辺の地図**: 検索した地点にピンを立てた国土地理院の地図を表示します。拡大・縮小やドラッグで周辺を見られます。日本国内は詳しく表示されますが、海外は大まかな地図になります。
- **この街について**: ウィキペディア日本語版から、次の情報を表示します。
  - 都市の紹介文(記事の冒頭3文)と記事へのリンク
  - 名産品・特産品:記事の「名産」「特産」「名物」「郷土料理」「伝統工芸」を含む節に箇条書きで書かれている項目。記事に記載がない場合は表示されません。
  - 周辺の観光スポット:周辺10km以内にある記事のうち、過去30日によく読まれている順に最大8件(駅・学校・役所などは除外)。名前を押すと記事が開きます。

スマートフォンの画面幅でも見やすいレイアウトになっています。

## ファイル構成

```
index.html   画面の構成
style.css    デザイン(スマホ対応)
app.js       APIからのデータ取得とグラフ・地図の表示
wiki.js      ウィキペディアからの街の情報の取得と表示
README.md    この説明書
```

`index.html` では `app.js?v=12` のように版番号を付けて読み込んでいます。ファイルを更新したときは、ブラウザが古いファイルを使い続けないように、この数字を上げてください。

## 注意事項

- インターネット接続が必要です(Open-Meteo API、Chart.js・Leaflet の CDN、地理院タイル、ウィキペディアにアクセスします)。
- 「この街について」の文章はウィキペディアの記事から取得しています(CC BY-SA 4.0)。記事の書き方によっては、名産品がうまく取り出せなかったり、観光スポットに関係の薄い場所が混ざったりします。
- Open-Meteo は非商用利用であれば無料・APIキー不要で使えます。詳しくは [Open-Meteo の利用条件](https://open-meteo.com/en/terms) を確認してください。

## 開発用の設定(Claude Code)

- `.claude/settings.json` と `.claude/hooks/confirm-push.sh`:Claude Code が `git push` を実行する直前に、プッシュされるコミット・変更ファイル・差分(長い場合は先頭4000文字)を表示し、承認を求めるフックです。承認しなければプッシュは実行されません。
